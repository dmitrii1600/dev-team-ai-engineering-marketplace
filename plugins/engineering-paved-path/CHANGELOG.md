# Changelog

Format: [Keep a Changelog](https://keepachangelog.com/), versions follow [SemVer](https://semver.org/).

## [1.0.0] - 2026-10-15

### Added

- Skill `react-best-practices`: React component, state and hooks practices with a severity-tagged anti-pattern catalogue.
- Skill `next-best-practices`: Next.js App Router conventions, RSC boundaries, data patterns, metadata, error handling, image and font optimisation, bundling and self-hosting.
- Skill `frontend-ui-architecture`: where frontend code lives — colocation, the promotion ladder, layers and import boundaries, component splitting, App Router organisation.
- Skill `fastify-best-practices`: Fastify plugins, routes, schemas, hooks, error handling, testing, performance and deployment rules.
- Skill `onion-architecture`: backend rings, the eleven dependency rules, sample lint and dependency-cruiser configs, and the exception policy.
- Skill `react-testing-library`: user-flow testing with React Testing Library and Vitest, with setup, spec templates and a matcher reference in `references/`.
- Skill `security`: review-time OWASP Top 10:2025 catalogue with confidence-based reporting, checklists and unsafe/safe examples.
- Skill `skill-routing`: file-group → skill table, the write-time vs review-time split, severity mapping and the load-once rule, overridable per project.
